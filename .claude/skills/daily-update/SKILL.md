# Daily update

The site reads two data files (see `website/notes.md`):

- `website/data/today.js` (`TODAY`): the 오늘 panel's weekly list (mood + 써먹을 표현 per day) and the weather phrase bank. Filled once a week by `website-update` (step 1). The page picks today's entry itself and fetches the weather live from Open-Meteo, so **this skill doesn't touch `today.js`**. Only check: if `TODAY.days` has no entry for today or later, tell the user the list ran out and suggest `/website-update`.
- `website/data/study.js` (`STUDY`): generated by `website/build_data.py` from `weeks/`, `progress/`, `Grammar/`, `Listening/` and Anki. Never edit it by hand.

## Rebuild `study.js`

```bash
python3 -I website/build_data.py
```

Run it from the repo root. It reads Anki through `.claude/skills/_shared/anki.py` (works with Anki open or closed): streak, today's reviews, today's pinned words (ticker and flash cards), most-missed cards (자꾸 까먹는 단어). It also reads the week's plan (D-n, 진도 bar, schedule), `progress/grammar.md` (levels), `progress/mistakes.md` (자주 틀리는 문법, 실수 종류) and the week's listening clip, and keeps one snapshot per week in `progress/stats.json` for the trend arrows.

If it prints an Anki error, the rest of the site still updates; say so in one line.

## Check

Run `node --check website/data/today.js` and `node --check website/data/study.js`. Don't stage or commit anything in `website/` or `progress/stats.json`. Don't push. Then tell the user what changed in a few lines (pinned words count, streak).
