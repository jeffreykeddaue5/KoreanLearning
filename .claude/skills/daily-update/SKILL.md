# Daily update

The site reads two data files (see `website/notes.md`):

- `website/data/today.js` (`TODAY`): hand-written daily bits — weather, mood, 써먹을 표현. This skill edits weather and mood.
- `website/data/study.js` (`STUDY`): generated by `website/build_data.py` from `weeks/`, `progress/`, `Grammar/`, `Listening/` and Anki. Never edit it by hand.

Keep everything short and simple: this is a personal blog, not study notes.

## 0. Once a day only

Compare `date` in `TODAY` with today (`date +%F`):

- Same date: weather and mood are done for today. Do step 3 only.
- Different date: do steps 1–3, then set `date` to today.

## 1. 오늘 날씨 (`TODAY.weather`)

Get today's weather for Northern Virginia (Fairfax) from Open-Meteo, no key needed:

```bash
curl -s 'https://api.open-meteo.com/v1/forecast?latitude=38.85&longitude=-77.30&current=temperature_2m,weather_code&daily=weather_code,temperature_2m_max,temperature_2m_min,precipitation_probability_max&timezone=America%2FNew_York&forecast_days=1'
```

Use the daily `weather_code` (WMO: 0 맑음, 1–3 구름 조금/흐림, 45–48 안개, 51–67 비, 71–77 눈, 80–82 소나기, 95+ 뇌우). If the request fails, say so and leave the weather as it is. Don't guess.

- `art`: two short lines of ASCII to match (`\n` between lines): rain `' , ' , '`, snow `* . * . *`, sun `\ | /` / `— ☼ —`, clouds `.--.` / `(    ).`.
- `label`: `날씨 · NN°C` with the current temperature, rounded.
- `tip`: high/low and a short tip, e.g. 우산을 챙기세요, 겉옷을 챙기세요, 햇볕이 좋아요.
- `phrase`: one natural Korean expression for today's weather in …요 form, e.g. 하늘이 쨍해요 (no 「」, the page adds them). Not the one that's there now.
- `note`: its key word with a short meaning in simple Korean, e.g. 쨍하다: 햇빛이 아주 밝고 맑다.
- `meaning`: the key word's English meaning (blurred until hover/tap).

## 2. 오늘의 기분 (`TODAY.mood`)

Pick one feeling word (adjective or expression) the user hasn't studied: not in `mood.past`, and not in Anki (`python3 -I .claude/skills/_shared/anki.py words | grep -x <word>` prints nothing). Fit it to the day if you can, e.g. the weather or how the latest session in `progress/log.md` went (뿌듯하다 after a strong session).

- `face`: a kaomoji that fits.
- `word`: the word.
- `sentence`: a short sentence with it, e.g. 오늘 문법을 다 맞혀서 뿌듯해요.
- `meaning`: its English meaning.
- Append the word to `past`.

## 3. Rebuild `study.js`

```bash
python3 -I website/build_data.py
```

Run it from the repo root. It reads Anki through `.claude/skills/_shared/anki.py` (works with Anki open or closed): streak, today's reviews, today's pinned words (ticker and flash cards), most-missed cards (자꾸 까먹는 단어). It also reads the week's plan (D-n, 진도 bar, schedule), `progress/grammar.md` (levels), `progress/mistakes.md` (자주 틀리는 문법, 실수 종류) and the week's listening clip, and keeps one snapshot per week in `progress/stats.json` for the trend arrows.

If it prints an Anki error, the rest of the site still updates; say so in one line.

## Check

Run `node --check website/data/today.js` and `node --check website/data/study.js`. Don't stage or commit anything in `website/` or `progress/stats.json`. Don't push. Then tell the user what changed in a few lines (weather, mood word, pinned words count, streak).
