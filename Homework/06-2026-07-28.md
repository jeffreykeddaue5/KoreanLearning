## 📝숙제 Homework








1.I ended up not being able to get tickets because I booked late. The only seats left were the very front ones, you see. So I'm thinking about going next week.
🔁 늦게 예약한 탓에 표를 못 사게 됐어요. (✅) 
맨 앞자리밖에 없었거든요. (❌) 
➡️’남은 자리’가 맨 앞자리밖에 없었거든요. (✅) 
그래서 다음 주에 갈까 해요. (✅) 
💡 Use because of, due to (negative result)
 💡 Use To come to... / end up... / become (through circumstances)
 💡 Use There is nothing but... / only
 💡 Use explain the reason (soft, nice tone)
 💡 Use Thinking about doing something; considering a plan




2.Judging from how quiet it is, it seems the movie already started. It's true that we're a bit late, but it can't be helped. We'd better just go in holding our popcorn.
🔁 조용한 걸 보니까 영화가 이미 ‘시작하는’ 모양이에요. (❌) 
     조용한 걸 보니까 영화가 이미 ‘시작한’ 모양이에요 (✅) 
조금 늦게 오기는 했지만 어쩔 수 없어요. (✅) 
팝콘 든 채로 들어가는 게 좋겠어요. (✅) 
 💡 Use judging from, seeing that
 💡 Use seems like, appears that
 💡 Use although/it's true that... but
 💡 Use while doing, while being in a state
 💡 Use It would be good to... / You'd better... 





3.You know our tastes are different. I like quiet movies whereas my brother likes loud ones. So it took as much as an hour to choose. I hope we decide faster next time.
🔁 
우리 취향이 다르잖아요.(✅) 
저는 조용한 영화를 좋아하는 반면에 형은 ‘정신사나운’ 영화를 좋아해요.  (✅) 그래서 영화를 고르는 데 한 시간이나 걸렸어요.  (✅) 
다음에 빨리 더 고르면 좋겠어요. (✅) 

💡 Use You know, As you know, remember
 💡 Use whereas, while, on the other hand
 💡 Use even, rather
 💡 Use the speaker is impressed by a fact he/she learned anew
 💡 Use I wish/hope 













4.I couldn't see the screen because the person in front was sitting with a hat on. I had no idea it would be this frustrating. Next time it would be better to get a back seat. That's better, isn't it?
🔁 
모자를 쓴 채로 사람이 제 바로 앞자리에 앉은 탓에 ‘장면’을 볼 수 없었어요.  (❌) 
➡️모자를 쓴 채로 사람이 제 바로 앞자리에 앉안 탓에 ‘화면’을 
볼 수 없었어요 (✅) 
cf)장면 scene, footage, 화면 screen 

이렇게 짜증날 줄 몰랐어요. (✅) 
다음에는 뒷자리를 구하는 게 좋겠어요. ‘더 좋죠?’
➡️다음에는 뒷자를 구하는게 좋겠어요. ‘그게 더 낫겠지요?’
cf)낫다 Better, 나다 (땀이 나다)
💡 Use while doing, while being in a state
 💡 Use because of, due to (negative result)
 💡 Use didn't know that, had no idea
 💡 Use It would be good to... / You'd better...
 💡 Use Seeking agreement, confirming, softening 



5.Judging from the fact that the tickets are all sold out, I guess it's really popular. I don't know if I can see it today. I waited from the morning because I was worried I wouldn't be able to see it.
🔁 
표를 다 ‘파는’ 걸 보니까 인기가 많은가 봐요. (❌) 
➡️표가 다 ‘팔리는’ 걸 보니까 인기가 많은가 봐요 (✅) 
오늘 볼 수 있는지 모르겠어요. (✅) 
볼 수 없을까 봐 아침부터 기다렸거든요. (✅)  

cf)표를 팔다 to sell tickets 
    vs 표가 팔리다 tickets are sold/tickets sell 

    ex)오늘 표가 별로 안 팔렸어요 (✅) 
        🔁 Not many tickets were sold today.
  
    ex)제 친구가 친구에게 표를 팔아요 (✅) 
         🔁 My friend sells tickets to a friend
     
cf)팔다 to sell vs 팔리다 to be sold  
💡 Use judging from, seeing that
 💡 Use It seems...; I guess... (based on evidence)
 💡 Use Not sure, the truth is unknown/uncertain
 💡 Use Worried that something might happen
 💡 Use explain the reason (soft, nice tone)
