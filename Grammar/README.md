# Grammar Points

My numbered grammar points, grouped by what they do in conversation. Points that are easy to mix up are in the same file, and each file ends with a **Compare** table.

Each point has spoken examples, ❌ → ✅ lines for common mistakes (many from my own homework, marked `(L#)` for the lesson in `Homework/`), and notes.

| File | What's in it |
|---|---|

| [guessing.md](guessing.md) | Guessing from evidence, possibility |
| [heard-and-experienced.md](heard-and-experienced.md) | Things you heard, saw, or didn't know |
| [contrast.md](contrast.md) | Contrast, "even if", "for a…" |
| [time-and-sequence.md](time-and-sequence.md) | Order of events, interruptions, change |
