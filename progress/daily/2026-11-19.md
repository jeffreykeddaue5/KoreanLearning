| grammar Q4 | 맞춤법 | 공창 · 갈 만행요 | 곱창 · 갈 만해요 | typos (small slip) |
| grammar Q3 | 네, 드라마를 보고 있어요 … 처음 봤을 때 정주행했어요 | 네, 요즘 (드라마 이름) 보고 있는데 완전 볼 만해요. 지난주에 보기 시작했는데 벌써 다 정주행했어요 | name it + -는데 links the lines; 보기 시작했는데 (L21) says when it started |
| grammar Q2 | 치킨 식당에 가기로 했어요 … 매일 치킨을 먹어서 | 치킨집에 가기로 했어요 … 요즘 치킨을 너무 자주 먹어서 좀 질렸어요 | 치킨집 = the everyday word; 매일 sounds literal, 너무 자주 + 좀 is softer |
| grammar Q2 | 맞춤법 | 치킨 시당 | 치킨 식당 | spelling: 식당 (small slip) |
| grammar Q1 | 웬만하면 일을 안 하기로 했어요 | 웬만하면 일은 안 하려고요 / 일은 안 하기로 했어요 | 웬만하면 (if I can help it) fits -려고요 best; -기로 했어요 is firmer, so 웬만하면 can drop; 일은 = contrast (work, at least) |
| grammar intro | 저한테 볼만하다고 말했어요 | 볼 만하다고 하더라고요 / 볼 만하대요 | 말했어요 is fine; -다고 하다 / -대요 is the everyday way to report; space: 볼 만하다 |
| grammar intro | 어휘 | 2000초반년 드라마 | 2000년대 초반 드라마 | decade = 2000년대; 초반 comes after (L21: 2000년 초반) |
| grammar intro | 시제 | 드라마에 빠져요 | 드라마에 빠졌어요 | 빠지다 = a change; being hooked now = 빠졌어요 (like 결혼했어요) |
