## Recurring mistakes

Mistakes that happened in 2 or more sessions. No count; being right adds `· right <date>`, being wrong adds the date and sentence. Remove an item once it stops happening.

- [시제] Tense doesn't match the time: present for past events (연결할 수 없어요), past for future plans (끝나자마자 샤워했어요), past for ongoing (요즘 버텼거든요), present for past (많거든요, 걸리는 탓에, 사고 싶은데) (2026-10-08, 2026-10-09, 2026-10-11, 2026-10-12, 2026-10-13 warm-up: 요즘 버텼거든요 again, 2026-10-17: 잃어버리나 봐요, 출발해요 for past, 2026-10-20 warm-up: 늘 … 뒀어요 for a habit → 둬요, 2026-10-23: 사고 싶은데 → 싶었는데, 2026-10-25: 풀리기까지 2달이 걸려요 → 걸릴 거예요, 500달러가 들어요 → 들었어요, 2026-10-26: 매진되나 봐요 for the future → 매진될 것 같아요, 2026-10-29 warm-up: 풀리기까지 … 걸었어요 → 걸릴 거예요, 500달러가 들어요 → 들었어요, 2026-10-30 drill: 30만 원이 들어요 → 들었어요, 2026-11-06: 팔이 쑤셨어요 (now) → 쑤셔요, 지금 바빴다고 → 바쁘다고, 주말 날씨가 좋더라고요 → 좋을 거래요) · right 2026-11-07
- [문법] -(으)ㄹ까 봐: adds -서 (걸릴까 봐서, L7; 멀미할까 봐서, 2026-10-17) and drops 못 (갈까 봐, L16; 받을까 봐, 2026-10-17) · right 2026-10-18
- [문법] Discovery → -아/어 보니까: 확인하다 보니 (2026-10-17), 찾아볼 때 가다 보니 (2026-10-18), 확인해서 품절됐어요 (2026-10-23), 확인하자마자 품절됐어요 (2026-10-26 warm-up) → 확인해 보니까 품절됐더라고요 · right unprompted 2026-10-29
- [조사] N에 N for a compound noun: 한국에 여행은 → 한국 여행은 (2026-10-17), 일본에 여행은 → 일본 여행은 (2026-10-20 warm-up)
- [문법] -(으)나 마나 on the wrong action: 커피를 줄이나 마나 → 말하나 마나 와이프는 안 믿을 거예요 (2026-10-22, 2026-10-25 warm-up)
- [문법] -(으)ㄹ 뻔하다 + feelings / past "if": 창피할 뻔했어요 → 보냈으면 창피했을 거예요; 사지 않으면 못 살 거예요 → 안 샀으면 못 살 뻔했어요 (2026-10-23, 2026-10-26 warm-up) · right 2026-10-30
- [조사] Body part takes 을/를 with 다치다: 다리가 다칠 뻔했어요 → 다리를 다칠 뻔했어요 (2026-10-23, 2026-10-29 warm-up) · right 2026-10-30
- [문법] 남은 N이 + X밖에 없다: 맨 앞자리밖에 없었거든요 → 남은 자리가 맨 앞자리밖에 없었거든요 (L6); 남은 식빵밖에 없었거든요 → 남은 빵이 식빵밖에 없었거든요 (2026-10-30 drill) · right 2026-11-07
- [어순] 어쩐지 in the same clause as the reason: 세일이 많은 만큼/많아서 어쩐지 … 걸렸어요 → 세일이 많더라고요. 어쩐지 주차하는 데 30분이나 걸리더라고요 (2026-10-29, 2026-11-04 warm-up) · right 2026-11-07
- [조사] N에 집중하다 / 몰입하다: 영화를 집중할 수 없었어요 → 영화에 (2026-10-29), 게임을 몰입하느라고 → 게임에 (2026-11-06) · right 2026-11-07
- [조사] -(으)러 가다/다니다 → place + 에, not 에서: 공원에서 산책하러 → 공원에 (2026-11-04), 바다에서 수영하러 가고 싶어요 → 바다에 (2026-11-07 drill)
- [어휘] 커피를 먹다 → 커피를 마시다 (2026-10-11, 2026-10-12 and earlier, 2026-10-22: 많이 먹은 탓에)

## Practice mistakes

Mistakes corrected in sessions. Each session's warm-up picks from here (lowest count, then oldest). +1 when fixed, reset to 0/2 when wrong, delete at 2/2. Same mistake again in a later session → move to Recurring. Max 10 items, drop the oldest.

- [문법] 늦어도 발표를 해냈어요 → 늦었지만 발표를 해냈어요 (-아/어도 = even if, not for something that already happened) (2026-10-31) · 1/2
- [문법] 마라톤을 끝낼까 봐 걱정이었어요 → 마라톤을 못 끝낼까 봐 걱정이었어요 (worry about not doing it → 못, same as L16) (2026-10-31) · 1/2
- [조사] 오늘에 뒤끝이 없는 것 같아요 → 오늘은 뒤끝이 없는 것 같아요 (오늘 doesn't take 에) (2026-10-31) · 1/2
- [문법] 물입한가 봐요 → 몰입했나 봐요 (몰입하다 is a verb → -나 봐요; past → 했나) (2026-11-04) · 1/2
- [어휘] 업무를 살제한 탓에 → 파일을 삭제한 탓에 (삭제, delete a file) (2026-11-04) · 1/2
- [조사] 게임을 물입하느라고 → 게임에 몰입하느라고 (N에 몰입하다, like N에 집중하다) (2026-11-06) · 0/2
- [어휘] 게임은 씌우는 반면에 → 게임은 쉬운 반면에 (쉽다 → 쉬운; 씌우다 = cover) (2026-11-06) · 1/2
- [문법] 동료가 이야기하기 때문에 방해되느라고 칼퇴를 안 했어요 → 동료들이 이야기해서 일하는 데 방해됐어요. 그래서 칼퇴를 못 했어요 (-느라고 = I was busy doing A) (2026-11-06) · 1/2
- [시제] 지금 너무 바빴다고 메시지를 보내요 → 지금 바쁘다고 (quoting "I'm busy now" → present) (2026-11-06) · 0/2
