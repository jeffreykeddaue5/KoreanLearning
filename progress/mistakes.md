## Recurring mistakes

Mistakes that happened in 2 or more sessions. No count; being right adds `· right <date>`, being wrong adds the date and sentence. Remove an item once it stops happening.

- [시제] Tense doesn't match the time: present for past events (연결할 수 없어요), past for future plans (끝나자마자 샤워했어요), past for ongoing (요즘 버텼거든요), present for past (많거든요, 걸리는 탓에, 사고 싶은데) (2026-10-08, 2026-10-09, 2026-10-11, 2026-10-12, 2026-10-13 warm-up: 요즘 버텼거든요 again, 2026-10-17: 잃어버리나 봐요, 출발해요 for past, 2026-10-20 warm-up: 늘 … 뒀어요 for a habit → 둬요, 2026-10-23: 사고 싶은데 → 싶었는데, 2026-10-25: 풀리기까지 2달이 걸려요 → 걸릴 거예요, 500달러가 들어요 → 들었어요, 2026-10-26: 매진되나 봐요 for the future → 매진될 것 같아요, 2026-10-29 warm-up: 풀리기까지 … 걸었어요 → 걸릴 거예요, 500달러가 들어요 → 들었어요, 2026-10-30 drill: 30만 원이 들어요 → 들었어요, 2026-11-06: 팔이 쑤셨어요 (now) → 쑤셔요, 지금 바빴다고 → 바쁘다고, 주말 날씨가 좋더라고요 → 좋을 거래요, 2026-11-07 feelings drill: 친구를 못 만나기 때문에 서운했어요 → 못 만나서, 2026-11-08: 서운할 지도 몰랐지만 (guess now) → 서운할지도 모르지만, 2026-11-09: 이직 혼자 다 해야 돼요 (future guess) → 해야 할 거예요, 2026-11-10 weekly: 좋길래 공원에 가요 → 갔어요, 2026-11-11 prep: 잊어버리는 탓에 → 잊어버린 탓에)
- [문법] -(으)ㄹ까 봐: adds -서 (걸릴까 봐서, L7; 멀미할까 봐서, 2026-10-17) and drops 못 (갈까 봐, L16; 받을까 봐, 2026-10-17) · right 2026-10-18
- [문법] Discovery → -아/어 보니까: 확인하다 보니 (2026-10-17), 찾아볼 때 가다 보니 (2026-10-18), 확인해서 품절됐어요 (2026-10-23), 확인하자마자 품절됐어요 (2026-10-26 warm-up) → 확인해 보니까 품절됐더라고요 · right unprompted 2026-10-29
- [조사] N에 N for a compound noun: 한국에 여행은 → 한국 여행은 (2026-10-17), 일본에 여행은 → 일본 여행은 (2026-10-20 warm-up)
- [문법] -(으)나 마나 on the wrong action: 커피를 줄이나 마나 → 말하나 마나 와이프는 안 믿을 거예요 (2026-10-22, 2026-10-25 warm-up)
- [문법] -(으)ㄹ 뻔하다 + feelings / past "if": 창피할 뻔했어요 → 보냈으면 창피했을 거예요; 사지 않으면 못 살 거예요 → 안 샀으면 못 살 뻔했어요 (2026-10-23, 2026-10-26 warm-up) · right 2026-10-30
- [조사] Body part takes 을/를 with 다치다: 다리가 다칠 뻔했어요 → 다리를 다칠 뻔했어요 (2026-10-23, 2026-10-29 warm-up) · right 2026-10-30
- [문법] 남은 N이 + X밖에 없다: 맨 앞자리밖에 없었거든요 → 남은 자리가 맨 앞자리밖에 없었거든요 (L6); 남은 식빵밖에 없었거든요 → 남은 빵이 식빵밖에 없었거든요 (2026-10-30 drill) · right 2026-11-07
- [어순] 어쩐지 in the same clause as the reason: 세일이 많은 만큼/많아서 어쩐지 … 걸렸어요 → 세일이 많더라고요. 어쩐지 주차하는 데 30분이나 걸리더라고요 (2026-10-29, 2026-11-04 warm-up) · right 2026-11-07
- [조사] N에 집중하다 / 몰입하다: 영화를 집중할 수 없었어요 → 영화에 (2026-10-29), 게임을 몰입하느라고 → 게임에 (2026-11-06) · right 2026-11-07 · right 2026-11-08
- [조사] -(으)러 가다/다니다 → place + 에, not 에서: 공원에서 산책하러 → 공원에 (2026-11-04), 바다에서 수영하러 가고 싶어요 → 바다에 (2026-11-07 drill) · right 2026-11-08
- [문법] 이/가 + transitive verb → intransitive/passive: 표를 다 파는 → 표가 다 팔리는 (L6), 계획이 바꾸는 바람에 → 계획이 바뀌는 바람에 (2026-11-12)
- [어휘] 커피를 먹다 → 커피를 마시다 (2026-10-11, 2026-10-12 and earlier, 2026-10-22: 많이 먹은 탓에, 2026-11-10 homework: 커피를 먹었더니 → 마셨더니)
- [문법] State → change before -기까지 ("until I got ___" → -아/어지다 / -게 되다): 익숙하기까지 → 익숙해지기까지 (2026-11-10 homework), 잘 하기까지 → 잘하게 되기까지 (2026-11-11 prep)

## Practice mistakes

Mistakes corrected in sessions. Each session's warm-up picks from here (lowest count, then oldest). +1 when fixed, reset to 0/2 when wrong, delete at 2/2. Same mistake again in a later session → move to Recurring. Max 10 items, drop the oldest.

- [조사] 일이 쉬운걸요. 그냥 마감이 많거든요 → 일은 쉬운걸요 (contrast → 은/는) (2026-11-09) · 1/2
- [문법] 제가 청소하느라고 남편이 저녁을 (못) 만들었어요 → 제가 청소하느라고 저녁을 못 만들었어요 (-느라(고): same subject in both halves) (2026-11-10 weekly) · 0/2
- [문법] 강아지를 입양하다면서요? → 입양했다면서요? (conjugate the reported verb first: 했다 + 면서요) (2026-11-10 weekly) · 0/2
- [문법] 집에 왔더니 바로 잠들었어요 → 집에 오자마자 잠들었어요 (-았/었더니 = action → what you found, not plain sequence) (2026-11-10 weekly) · 0/2
- [문법] 남편이 연어 덮밥을 먹었더니 → 남편이 먹더니 / 제가 만들어 줬더니 (-았/었더니 = my own action; someone else's → -더니) (2026-11-11 prep) · 0/2
- [어휘] 양이 너무 커서 → 양이 너무 많아서 (양 goes with 많다/적다) (2026-11-11 prep) · 0/2
- [문법] 새 게임을 하기 제일 재미있었어요 → 새 게임을 한 게 ("doing X was the most fun" → -(으)ㄴ 게) (2026-11-11 prep) · 0/2
- [문법] 그림을 많이 그려 버렸는데 → 그렸는데 (-아/어 버리다 needs 'completely + regret/relief', not a plain past fact) (2026-11-12) · 0/2
- [어휘] 그림을 잘 못해요 → 그림을 잘 못 그려요 (keep 그리다; no 그림을 하다) (2026-11-12) · 0/2
- [어휘] 햄버거 4개를 실것 먹어 버렸어요 → 햄버거를 실컷 먹었어요 / 4개나 먹어 버렸어요 (실컷 = as much as I wanted, no exact count) (2026-11-12) · 0/2
